📝 Descrição do Projeto
Este projeto explora a intersecção entre criatividade humana e Inteligência Artificial. Utilizando técnicas de RAG (Retrieval-Augmented Generation) através do Gemini Gems, foi criado um assistente especializado na análise lírica inspirado em K-pop e BTS. O objetivo final foi a produção de um EP com 5 faixas inéditas, cujas letras foram geradas pela IA e a produção musical realizada via Suno AI.

🛠️ Tecnologias Utilizadas
Gemini Gems: Criação de base de conhecimento e geração de letras.
Suno AI: Geração de áudio e arranjos instrumentais.
GitHub: Documentação e versionamento do projeto.

📄 Processo de Criação
Curadoria: Seleção de letras base para treinamento da persona do assistente.
Prompt Engineering: Configuração das instruções do Gems para mimetizar o vocabulário, métrica e sentimentalismo do K-pop.
Produção: Geração das letras e posterior conversão em áudio no Suno AI, utilizando prompts de estilo específicos para cada faixa.
