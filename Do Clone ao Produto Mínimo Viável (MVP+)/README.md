# 🚀 Gemini AI Studio Application

Este projeto consiste em uma aplicação web interativa integrada à API do Gemini, desenvolvida a partir de um protótipo estruturado no Google AI Studio. A aplicação combina o poder de modelos de linguagem de última geração com uma interface moderna, responsiva e focada na experiência do usuário (UX), servindo como um sólido portfólio para engenharia de prompts e desenvolvimento de software.

O ecossistema foi desenhado para ser escalável, modular e de fácil manutenção, aplicando conceitos fundamentais de Análise e Desenvolvimento de Sistemas (ADS).

---

## 🛠️ Tecnologias e Arquitetura

A stack tecnológica foi selecionada para garantir alta performance, renderização eficiente e estilização utilitária:

- **Core:** Node.js & React (Next.js) para renderização híbrida e rotas otimizadas.
- **Inteligência Artificial:** Integração nativa com a API do Gemini via Google AI Studio.
- **Estilização:** Tailwind CSS para construção de interfaces fluidas e design system consistente.
- **Ambiente:** Dotenv para gerenciamento seguro de credenciais e chaves de API.

---

## 🚀 Funcionalidades Principais

- **Processamento em Tempo Real:** Comunicação assíncrona com os modelos do Gemini para respostas instantâneas.
- **Interface Responsiva:** Adaptação completa para dispositivos mobile, tablets e desktops.
- **Design System Inteligente:** Paleta de cores otimizada para legibilidade e componentes baseados em usabilidade.
- **Arquitetura Segura:** Consumo de chaves de API mascaradas através de variáveis de ambiente no lado do servidor (Server-Side).
